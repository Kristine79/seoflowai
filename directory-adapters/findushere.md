## Known Issues & Solutions

### 1. Dynamic Region/City Dropdowns
- **Issue**: `select[name="region"]` doesn't exist until country selected
- **Solution**: Wait 4s after country selection, then region select has name `business_region`
- **Note**: City select has NO id, use `select[name="business_city"]`

### 2. Anti-Bot pass_word Fields
- **Issue**: `form.submit()` without filling password fails silently (form re-renders empty)
- **Solution**: Type password FIRST (triggers JS to create pass_word token), wait 3s, then submit
- **Note**: Never manually set pass_word — JS-generated token is validated server-side

### 3. Silent Form Re-render
- **Issue**: Failed submit returns form with empty fields, no error message
- **Solution**: Check for success text: "Business listing has been created"

### 4. Dashboard Form Index
- **Issue**: Form order on dashboard is fixed: [0]=contact, [1]=basics, [2]=address, [3]=map, [4]=category, [5]=description, [6]=page_removal
- **Solution**: Use `querySelectorAll('form[action*="update_business_details"]')[N]` — order is stable

### 5. Page Not Found Returns 200
- **Issue**: Non-existent pages return HTTP 200 with "Page Not Found" text
- **Solution**: Check page TITLE contains business name, not HTTP status

## Lessons Learned

### 1. URL Accuracy
**Problem**: Initial check used wrong URL (findushere.com — travel blog)  
**Solution**: Always verify exact URL from client's list (find-us-here.com — business directory)

### 2. JS-Generated Anti-Bot Tokens
**Problem**: pass_word/confirm_pass_word created dynamically by JS  
**Solution**: Type password with real keyboard events, wait for JS, then submit

### 3. Dynamic Dropdowns
**Problem**: Region/City selects require sequential selection  
**Solution**: 4s delays after each selection to allow AJAX population

### 4. Success Verification
**Problem**: Page Not Found returns HTTP 200  
**Solution**: Verify title/content, not just HTTP status
